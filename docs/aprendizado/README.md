# Diário de aprendizado

Registro do que foi estudado, testado e errado. O objetivo é consolidar o entendimento dos mecanismos,
não copiar comandos.

## Formato sugerido de cada entrada

Arquivo `AAAA-MM-DD-tema.md`:

```markdown
# Tema

## O que eu queria entender
## Como funciona (com minhas palavras)
## O que testei (e o resultado)
## O que deu errado e por quê
## Perguntas em aberto
## Fontes
```
